# Nova 架构

目标是给开发建立明确、精简、可验证且可复用的公共技术边界。架构导航直接保存在七章蓝图中；不生成独立架构索引、选型报告、ADR、审计或可从代码恢复的说明。

## 准入与加载

1. 先确定目标仓库并读取项目规则。蓝图不存在时，本技能负责初始化，不把空白项目直接交给 Development。
2. 蓝图存在后，只有用户本次主动调用本技能或明确要求修改共享架构时才修改；普通开发只读取、复用和遵循现有架构。
3. 首轮读取蓝图中的项目定位、技术栈、代码结构、模块职责、公共约束、待开发工作和架构文档链接；只沿与当前请求直接相关的精确链接读取详细架构，不扫描整个 `.nova/architecture/` 或 `.nova/design/`。
4. 再定向研究入口、代表性代码、配置、部署和测试。只有证据不足以判断公共边界时才逐步扩大调查，不做全仓内容读取。
5. 是否需要架构决定，取决于不同选择是否会导致技术栈、运行形态、模块职责、依赖方向、数据所有权、公共接口、安全、失败恢复或部署边界发生不兼容变化；模块内部实现选择不扩大到架构阶段。
6. 既有蓝图和代码已完整约束目标且用户没有要求修改架构时，报告复用依据并交回 Development，不创建文件或形式性变更。

## 澄清与决策

出现真实差量时完整读取 [共享澄清 SOP](../nova-development/references/conversation-sop.md)，Architecture 与 Development 必须使用同一提问、委托、确认、中断和恢复逻辑。

从用户已确认的目标和项目事实推导技术候选，逐项解释用户可感知的成本、部署、数据、恢复和扩展影响，不要求用户在未知后果下直接选择产品名称。

至少检查并在实际需要时闭环：

- 语言、框架、运行形态和部署边界；
- 代码结构、系统分层、目录映射和允许依赖；
- 模块职责、共享能力和跨模块边界；
- 数据存储、所有权、一致性、迁移和生命周期；
- 公共 API、鉴权、错误语义和兼容策略；
- 事件、异步处理、重试、幂等、恢复与清理；
- 缓存、消息队列、Mock 或 fixture 等需求实际需要的基础设施；
- 性能、并发、资源上限、安全和可观测性等系统级不变量。

没有明确需要的基础设施写为“不使用”或“不适用”，不创建空目录和占位文档。架构应优先用清晰所有权、版本化接口和必要 Mock 消除并行开发依赖；只有业务顺序本身不可消除的依赖才保留为串行边界。

用户委托 AI 采用成熟方案时，可免除委托范围内低风险参数的逐项提问，但显著成本、部署边界、数据所有权、公共 API/事件、安全边界和共享失败语义仍须具体披露。将做法称为成熟或最佳实践前必须取得与本项目相关的外部证据。

## 交付物

创建或修改蓝图前完整读取 [蓝图架构规范](references/architecture-standard.md)，新建时使用 [蓝图模板](assets/PROJECT_BLUEPRINT.template.md)。

1. `.nova/PROJECT_BLUEPRINT.md` 保持七章结构，是技术栈、代码落位、模块职责、公共约束、待开发工作和架构导航的共同入口。
2. 公共边界能在蓝图中简洁、无歧义表达时直接写入对应章节。
3. 只有详细契约会使蓝图失去可读性时才创建 `.nova/architecture/<topic>.md`，并从蓝图“架构文档”章节使用精确相对链接引用。详细文件按需要承载 API、数据、事件、Mock、运行或恢复契约，不再建立第二层索引。
4. 实际迁移、共享类型、接口实现和工程骨架放在正常源码目录；架构文档只定义跨开发者必须一致的边界。
5. `.nova/SHARED_CAPABILITIES.md` 是可选的已实现能力复用目录，新建时使用 [共享能力目录模板](assets/SHARED_CAPABILITIES.template.md)。它不是架构索引，不替代代码和测试；没有已实现能力时不创建。
6. 只有用户明确要求规划或沉淀待办时才在蓝图增加待开发工作；完成后删除条目，设计文档保留，不记录 Review 状态。

写入前向用户展示本次架构摘要、取舍、影响和目标文件并取得明确确认。写入后运行与项目相称的结构、链接和项目验证，检查 diff，并按全局 `type(scope): 中文结果摘要` 规则创建 Conventional Commit；type 必须反映实际变更性质，不得使用流程型 `arch` 代替；不得添加专有编号或 trailers，不得自动 Review、push 或发布。

## 完成报告

首段说明实际形成或复用的架构结论，随后明确未改范围，再列关键契约、文件、验证、提交、就绪边界、遗留风险和下一步。报告只受提示词约束，不生成或校验临时报告。
