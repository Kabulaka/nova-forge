## WP-01 双宿主全局规则与安装

### 契约

| 契约 | 维度 | 语义键 | 唯一规则 |
|------|------|--------|----------|
| WP-01-C01 | 交付边界 | WP-01/交付范围 | 本工作包交付共享压缩续接规则、Codex 与 Claude Code 的全局规则及 Nova 技能安装、双宿主发现校验、README 安装说明和自动化测试；不交付 S-03 排除的运行时能力。 |
| WP-01-C02 | 参与者与权限 | WP-01/安装权限 | 安装只在用户显式执行脚本时修改用户级发现入口；脚本不得自动覆盖或合并用户已有普通文件或真实目录。 |
| WP-01-C03 | 触发与输入 | WP-01/安装输入 | 安装器从所在工作区确定唯一规则源和五个 Nova 技能源，默认一次处理 Codex 与 Claude Code；测试和诊断可显式提供隔离的宿主目录。 |
| WP-01-C04 | 结果、状态与不变量 | WP-01/发现结果 | 安装成功后，两个宿主的用户级全局规则入口解析到 S-01 的同一规则源，两个宿主各自的五个个人技能入口解析到同一组工作区技能目录。 |
| WP-01-C05 | 结果、状态与不变量 | WP-01/压缩保留内容 | 全局规则要求压缩摘要保留当前目标与阶段、用户已确认决定、明确排除、委托和候选身份、当前问题、活动交付范围、有效证据、文件与提交状态、下一动作，以及已加载控制内容的绝对路径与 SHA-256。 |
| WP-01-C06 | 结果、状态与不变量 | WP-01/续接读取 | 压缩后先沿用摘要继续；已加载控制内容的路径和指纹未变化时复用既有理解，不得为了保险重复全文读取，只有当前动作需要逐字正文而摘要不足或指纹变化时才精确取得受影响内容。 |
| WP-01-C07 | 结果、状态与不变量 | WP-01/续接提问 | 已回答事项不得因压缩被重置；只有缺失信息会改变当前行为且无法由当前会话记录或工作区事实确认时，才询问该具体差量。 |
| WP-01-C08 | 结果、状态与不变量 | WP-01/秘密排除 | 密码、访问令牌及其他秘密不得写入压缩摘要、安装诊断或长期记忆。 |
| WP-01-C09 | 失败与恢复 | WP-01/安装预检 | 修改前必须预检全部目标；任一目标为普通文件或真实目录时整体失败且零写入，正常或失效软链接只解除链接本身后重新建立，不删除链接原目标。 |
| WP-01-C10 | 失败与恢复 | WP-01/安装回滚 | 预检后发生意外失败时，安装器恢复本次已改变的原软链接并清理本次新建入口，不留下双宿主部分安装状态。 |
| WP-01-C11 | 失败与恢复 | WP-01/摘要缺失 | 宿主未保留某项内容时必须如实暴露缺口并按 C06、C07 定向恢复，不得伪造已恢复事实或以规则存在代替验收通过。 |
| WP-01-C12 | AI 决策边界 | WP-01/实施决策 | AI 可决定不改变外部行为的脚本内部结构、诊断措辞和测试夹具；新增宿主、覆盖或合并普通文件、引入 Hook/持久化/网络依赖、改变规则优先级或扩大跨会话能力必须再次确认。 |

### 验收

| 覆盖契约 | 场景 | 预期结果 |
|----------|------|----------|
| S-01、WP-01-C01、WP-01-C03、WP-01-C04 | 在隔离用户目录首次执行安装并运行发现校验 | Codex 与 Claude Code 的全局规则及五个 Nova 技能入口全部解析到当前工作区的唯一实体，README 命令与实际入口一致。 |
| WP-01-C04、WP-01-C09 | 对正常软链接和失效软链接重复安装 | 原链接本身先被解除后重新建立，最终解析到当前工作区，原链接目标内容未被删除。 |
| WP-01-C02、WP-01-C09 | 任一宿主目标存在普通文件或真实目录 | 安装在修改任何入口前失败，报告准确冲突目标，两个宿主均保持原状。 |
| WP-01-C10 | 在首个入口改变后注入一次后续链接创建失败 | 已改变入口恢复到原软链接或不存在状态，不留下部分安装结果。 |
| S-02、S-03、WP-01-C05、WP-01-C06、WP-01-C07、WP-01-C08、WP-01-C11 | 对普通任务与 Nova 任务构造压缩前后契约场景并检查全局规则 | 关键状态、路径和指纹具有明确保留指令，未变化内容复用、逐字内容定向恢复、缺失差量定向询问、秘密排除和尽力保证边界均由测试覆盖，不把规则文本存在等同于宿主绝不遗漏。 |
| WP-01-C12 | 请求覆盖已有普通规则文件或引入运行时恢复组件 | 当前工作包拒绝扩围并要求重新确认。 |
