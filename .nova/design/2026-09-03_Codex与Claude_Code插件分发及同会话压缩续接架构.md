| WP-01-C04 | 触发与输入 | WP-01/输入 | 输入为 `REQ-01a06524-60ee-7d61-a9f1-c588cd2bfdff@v1`、用户已确认决定、Codex 与 Claude Code 当前官方生命周期事实及 context-mode 1.0.169 的只读参考。 |
