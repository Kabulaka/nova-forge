<a id="shared-context"></a>
## 1. 共享约束

### 1.1 问题与成功结果

| 问题 | 成功结果 |
|------|----------|
| 项目级约束与功能设计混写会使蓝图膨胀并污染所有开发会话 | 蓝图只保存全局稳定事实，具体功能由可定位工作包承载 |
| 抽象模板和重复章节会给 AI 留出忽略契约或选择简单实现的空间 | 固定契约表、验收映射和完整示例共同限制生成结果 |
| 旧蓝图格式、待办来源和完成生命周期不可稳定追踪 | 版本 3 可检测、可说明、可受控迁移，完成后删待办但保留设计 |

### 1.2 共享契约

| 契约 | 已确认约束 |
|------|------------|
| S-01 | 每轮最多向用户提出一个问题，且只确认一个信息维度 |
| S-02 | 蓝图保存全局约束，设计保存待开发目标，代码/测试/配置证明当前实现 |
| S-03 | 一个史诗可含多个相关工作包，蓝图待办分别引用稳定锚点 |
| S-04 | 已确认要求、证据推断和待确认差量不得混写；非澄清状态不保留暂存章节 |
| S-05 | 工作包实现并验收后从蓝图删除，设计文档和锚点继续保留 |

## WP-01 技能重命名

### 契约

| 契约 | 维度 | 已确认约束 |

<a id="wp-03-validation"></a>
## WP-03 模板与校验

### 契约

| 契约 | 维度 | 已确认约束 |
|------|------|------------|
| WP-03-C01 | 交付边界 | 提供版本 2 蓝图、设计模板和标准库校验器；不自动推断需求 |
| WP-03-C02 | 参与者与权限 | 校验器只读输入，维护者依据错误修正文档 |
| WP-03-C03 | 触发与输入 | CLI 接收蓝图路径或 `--design` 加设计路径 |
| WP-03-C04 | 结果、状态与不变量 | 合法文档返回 0，结构、引用或生命周期错误返回 1 |
| WP-03-C05 | 失败与恢复 | 缺文件、读失败、断链或伪造结构给出可定位错误且不修改输入 |
| WP-03-C06 | AI 决策边界 | 可决定解析函数结构；放宽文档契约或增加依赖必须再次确认 |

### 验收

| 覆盖契约 | 场景 | 预期结果 |
|----------|------|----------|
| WP-03-C01、WP-03-C02、WP-03-C03、WP-03-C04 | 校验合法蓝图和多工作包设计 | 输出 PASS 并返回 0，文件摘要不变 |
| WP-03-C05、WP-03-C06 | 校验断链、自依赖或旧格式 | 输出具体错误并返回 1，不修改输入 |

## WP-07 校验、开发规则与版本控制同步

### 契约

| 契约 | 维度 | 已确认约束 |
|------|------|------------|

| WP-07-C02 | 参与者与权限 | 主代理实施测试，独立子代理 Review；全局文件只改用户授权条款 |

| WP-07-C06 | AI 决策边界 | 可拆分 Review 范围；初始化远程、改变作者身份或跳过 Review 必须再次确认 |

<a id="wp-08-context-loading"></a>
## WP-08 项目上下文渐进加载

### 契约

| 契约 | 维度 | 已确认约束 |
|------|------|------------|
| WP-08-C01 | 交付边界 | 优化项目定位、蓝图复用、规范路由和校验触发；不改变蓝图/设计版本、公开格式或校验器接口 |
| WP-08-C02 | 参与者与权限 | AI 在会话内维护目标路径与稳定快照 SHA-256，用户无需管理缓存；不得跨新会话或跨项目复用内容 |
| WP-08-C03 | 触发与输入 | 输入为用户请求、目标项目路径、蓝图存在性、版本和文件指纹；先确定目标项目并检查蓝图是否存在，再决定读取范围 |
| WP-08-C04 | 结果、状态与不变量 | 新会话先检查蓝图是否存在：存在则从稳定快照完整读取后按版本路由，不存在则直接进入新项目；同会话指纹未变时复用理解；版本 3 正常澄清不加载迁移 SOP，显式审计除外；旧版先通过三选一迁移决策门 |
| WP-08-C05 | 失败与恢复 | 目标、指纹或既有理解不确定时回退为完整读取；读取前后指纹不同则丢弃并重读，连续变化时停止；只有文档写入边界运行校验器 |
| WP-08-C06 | AI 决策边界 | 可选择哈希命令和目标章节；跳过首次完整读取、忽略文件变化或把当前目录蓝图当成未确认目标必须再次确认 |

### 验收

| 覆盖契约 | 场景 | 预期结果 |
|----------|------|----------|
| WP-08-C01、WP-08-C02、WP-08-C03、WP-08-C04 | 新会话进入版本 3 项目 | 先定位目标，完整读取一次蓝图并记录指纹，不加载迁移 SOP，不因纯对话运行校验器 |
| WP-08-C02、WP-08-C03、WP-08-C04、WP-08-C05 | 同一会话继续讨论且蓝图未变化 | 只读取目标待办或相关章节，不重复加载完整蓝图和访谈 SOP |
| WP-08-C03、WP-08-C04、WP-08-C05 | 蓝图版本缺失、不是 3 或外部修改 | 旧版先逐项报告七章职责和待归档局部内容，再只询问三选一迁移决定；用户选择前不追问功能或加载蓝图规范；指纹变化时废弃会话内理解并完整重读 |
| WP-08-C02、WP-08-C04、WP-08-C05 | 完整读取期间蓝图发生变化 | 丢弃正文与指纹并重读稳定快照；连续变化时停止，不复用混合版本理解 |
| WP-08-C03、WP-08-C04 | 新项目不存在蓝图 | 进入新项目澄清，不加载迁移 SOP 或虚构迁移决定 |
| WP-08-C01、WP-08-C05、WP-08-C06 | 创建、更新、迁移文档或修改引用与生命周期 | 写入后运行对应文档校验；纯解释和只读分析跳过校验 |
