<a id="wp-01-continuous-clarification"></a>
## WP-01 结构化答案后的连续澄清

### 契约

| 契约 | 维度 | 已确认约束 |
|------|------|------------|
| WP-01-C01 | 交付边界 | 只调整原生提问工具返回答案后的访谈推进；不改变单问题、阶段总结、工具选择和跨宿主规则 |
| WP-01-C02 | 参与者与权限 | 用户可随时暂停；AI 只根据已确认状态和当前话题的剩余差量决定是否继续 |
| WP-01-C03 | 触发与输入 | 原生工具成功返回一个答案后触发；输入为该答案、当前话题状态、剩余差量和工具状态 |
| WP-01-C04 | 结果、状态与不变量 | 先合并答案；有明确选项差量时继续一次原生单问题，开放式差量改发一个文本问题；不得预发、并发或重复问题 |
| WP-01-C05 | 失败与恢复 | 话题闭环、用户暂停、需先研究或写入、工具失败或呈现不明时停止，不追加可能重复的问题 |
| WP-01-C06 | AI 决策边界 | 可决定下一个影响最大的已知差量；扩大话题、跳过必要研究或把多个差量合并必须再次确认或拆分 |

### 验收

| 覆盖契约 | 场景 | 预期结果 |
|----------|------|----------|
| S-01、WP-01-C03、WP-01-C04 | 用户回答第一个结构化问题，当前话题仍有明确选项差量 | 简短确认后立即出现第二个结构化单问题 |
| S-01、WP-01-C04 | 连续存在多个差量 | 每次仅在前一答案返回后提出一个新问题，不并题、不预发、不重复 |
| WP-01-C03、WP-01-C04 | 下一差量是开放式事实问题 | 输出一个普通文本问题并等待，不因无法选项化而暂停无问 |
| WP-01-C02、WP-01-C05 | 当前话题闭环或用户要求暂停 | 停止连续澄清，不开启下一话题 |
| WP-01-C05 | 继续前必须研究或写入，或工具失败、呈现状态不明 | 先处理前置动作或安全停止，不追加可能重复的问题 |
| WP-01-C01、WP-01-C06 | 尝试改变工具路由、扩大话题或合并多个差量 | 保持原有跨宿主路由；越界决定需再次确认，多个差量继续拆分 |
