# Nova Forge v0.8.2

2026-09-21

## Overview

Nova Forge v0.8.2 修复 Development 已完成并通过验收后可能遗漏删除蓝图待开发项的问题，同时把正常连续开发与会话中断、压缩或续接后的恢复路径分开，避免日常开发为收尾重复读取蓝图或重跑仍有效的测试。

## Highlights

### 正常开发直接完成蓝图收尾

- 首次命中待开发工作时，仅在当前会话上下文保留任务名称和已有设计链接，不新增持久状态或台账。
- 实现和验收完成后直接删除同一待开发项，并从已有任务 diff 确认结果。
- 删除后不重新读取蓝图正文，也不为完成报告额外获取蓝图行号或增加独立工具轮次。

### 中断与续接时按需恢复

- 只有会话中断、压缩或续接后无法可靠恢复原条目时，才按已知任务名称或设计链接在蓝图第七章定向定位一次。
- 唯一匹配时同批删除；无法唯一匹配时保留条目并明确报告，避免误删其他待开发工作。
- 恢复过程不扫描其他待办或设计，也不重跑仍有效的测试证据。

### 契约与隔离验证

- 增加插件结构契约测试，固定正常路径零额外正文读取和恢复路径的范围边界。
- 仓库完整检查 54/54 通过，包结构与 Release Notes 校验通过。
- 在相同私有 provider、模型、推理等级和初始代码下完成修复前后隔离 5×5 对照；20/20 条件样本通过，未进入恢复分支时未观察到可确认的稳定性能回归。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.8.2
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

## Requirements

- Node.js 22.5 或更高版本；插件不会自动安装 Node.js 或 Bun。
- 支持插件 marketplace 的 Codex CLI，或 Claude Code 2.1.233 及兼容版本。
- 安装后审阅并信任插件 Hook，并在安装或升级后新开宿主会话。

## Upgrade Notes

- Codex 用户把 marketplace 固定引用更新为 `v0.8.2`，重新安装或刷新插件后新开会话。
- Claude Code 用户先更新 `nova-forge` marketplace，再更新或重新安装 `nova-forge@nova-forge`，随后新开会话。
- 本版本不迁移现有蓝图或设计文件；只有当前任务实际完成并通过验收时才删除对应待开发项。
- 本版本不增加状态机、台账、持久缓存、自动 Review、自动提交或发布行为。
