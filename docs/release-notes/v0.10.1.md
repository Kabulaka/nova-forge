# Nova Forge v0.10.1

2026-11-04

## Overview

Nova Forge v0.10.1 补齐独立顾问技能的界面展示元数据，使支持该配置的宿主可使用 `Nova Consult` 名称、简短描述和默认提示词。该版本为展示配置修复。

## Highlights

- 为 `nova-consult` 增加 `interface.display_name`，与其他 Nova 技能的命名形式保持一致。
- 补充用于技能列表的简短描述，以及调用时可使用的默认提示词。
- 保留 `allow_implicit_invocation: false`，独立顾问仍需显式调用；咨询职责、开发流程与 DSH 适配行为保持不变。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.10.1
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

### DeepSeek Harness

```bash
dsh plugin --profile headless add github:Kabulaka/nova-forge#v0.10.1
dsh --profile headless --dump-config
```

也可下载本 Release 的 `nova-forge-0.10.1.tgz`，校验 `SHA256SUMS` 后，通过 `dsh plugin --profile <profile> add /absolute/path/to/nova-forge-0.10.1.tgz` 安装。

## Requirements

- 共享 Hook 与维护脚本需要 Node.js 22.5 或更高版本；DSH 使用其宿主要求的 Node.js 运行时。
- Codex 与 Claude Code 需要支持原生插件的宿主版本；DSH 需要支持原生 bundle、技能 provider 和官方 hooks 兼容桥。
- 展示名称、简短描述及默认提示词是否呈现取决于宿主对 `agents/openai.yaml` 的支持。
- 本版本不新增依赖；独立顾问仍需要宿主提供隔离子代理及相应的模型、思考度参数支持。

## Upgrade Notes

- Codex 用户将 marketplace 固定引用更新为 `v0.10.1`，刷新或重新安装插件后新开会话以加载新元数据。
- Claude Code 用户更新 marketplace 和插件，DSH 用户在对应 profile 中更新；随后新开会话。
- 调用标识仍为 `nova-consult`；显示名称调整为 `Nova Consult` 不改变技能调用方式。
- YAML、技能、插件结构及打包检查已通过；本地检查不替代宿主界面的实际显示验收。
- 不迁移或改写用户的 AGENTS.md、蓝图、设计、全局技能目录和历史会话。
