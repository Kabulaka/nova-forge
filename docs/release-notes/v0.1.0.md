# Nova Forge v0.1.0

> 首个基线版本 · Codex 与 Claude Code 双宿主插件

## Overview

Nova Forge v0.1.0 建立从总体需求、共享架构、功能开发、本地提交到人工 Review 与审计关闭的版本化治理基线，并为 Codex 和 Claude Code 提供同源技能、全局规则、Hook 与本机会话检查点能力。

## Highlights

### Codex

- 提供原生 Codex 插件 manifest、GitHub marketplace、五个 Nova 技能和检查点 MCP。
- 支持 Codex CLI 插件发现、安装、启用和新会话加载；Codex IDE 可使用兼容发现链接。

### Claude Code

- 提供 Claude Code 插件 manifest、marketplace、生命周期 Hook 和同源 Nova 技能。
- 使用宿主原生插件数据目录保存本机会话检查点，不在插件状态中保存密码或访问令牌。

### Delivery Governance

- 覆盖总体需求、技术架构、开发交付、只读 Doctor 和人工 Review 五类稳定流程。
- 使用 schema 2 工作项、提交 trailers、交付台账、Review closure 与分片审计维持可追踪交付。

### Session Recovery

- 在语义边界与压缩生命周期保存结构化检查点，同一会话恢复时校验宿主、目录、状态版本和完整性。
- 输入超限、状态歧义、校验失败或检查点过期时关闭恢复路径，不静默注入不可信状态。

## Installation

运行时要求 Node.js 22.5 或更高版本。私有仓库安装需要当前用户已经具备 GitHub 仓库读取权限。

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.1.0
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

安装后请审阅并信任插件 Hook，然后新开会话使技能、Hook 与 MCP 生效。

## Requirements

- Node.js 22.5 或更高版本。
- 支持插件的 Codex CLI 或 Claude Code；Codex IDE 当前不提供插件入口。
- 运行治理校验和兼容安装器时需要 Python 3 标准库环境。

## Upgrade Notes

- 这是首个基线版本，不需要从旧版插件迁移。
- 已使用兼容软链接的宿主应先完成插件预检，再移除同宿主 Nova 软链接，避免插件入口与兼容入口并存。
- 禁用或卸载插件后如需回退，应先让插件退出，再恢复兼容链接并新开会话。
