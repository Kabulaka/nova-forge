# Nova Forge v0.10.2

2026-11-13

## Overview

Nova Forge v0.10.2 修复执行计划只停留在文字描述的问题：需要计划时，要求实际调用宿主提供的原生计划或待办工具。计划粒度、执行、进度维护与完成判断由执行任务的 agent 按实际情况处理，保持轻量开发流程。

## Highlights

- 明确在首次修改前创建或复用原生计划，文字说明不能代替工具调用；普通开发模式也可使用，无需开启 Plan mode。
- 补充 Codex 的 `update_plan`、Claude Code 的 `TaskCreate` / `TaskUpdate` 或 `TodoWrite`、DSH 的 `todo_write` 识别提示，以当前会话实际提供的工具及契约为准。
- 简化计划内容要求，不规定逐项状态切换和更新频率；同一任务续改或恢复时复用已有计划与进展，DSH 按工具契约提交完整清单。
- 原生计划由宿主保存和展示，不新增 Nova 计划或状态文件，也不增加审批或自动切换 Plan mode。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.10.2
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

### DeepSeek Harness

```bash
dsh plugin --profile headless add github:Kabulaka/nova-forge#v0.10.2
dsh --profile headless --dump-config
```

也可下载本 Release 的 `nova-forge-0.10.2.tgz`，校验 `SHA256SUMS` 后，通过 `dsh plugin --profile <profile> add /absolute/path/to/nova-forge-0.10.2.tgz` 安装。

## Requirements

- 共享 Hook 与维护脚本需要 Node.js 22.5 或更高版本；DSH 使用其宿主要求的 Node.js 运行时。
- Codex 与 Claude Code 需要支持原生插件的宿主版本；DSH 需要支持原生 bundle、技能 provider 和官方 hooks 兼容桥。
- 原生计划需要当前会话实际提供相应工具；清单外观和交互由宿主决定，不保证可点击 checkbox。
- 本版本不新增依赖，不更改宿主配置来启用计划工具。

## Upgrade Notes

- Codex 用户将 marketplace 固定引用更新为 `v0.10.2`，刷新或重新安装插件后新开会话；Claude Code 和 DSH 用户更新对应 marketplace、插件或 profile 后新开会话。
- 继续沿用既有计划触发条件，简单修改仍可直接实施；不新增计划审批步骤，也不要求统一的计划粒度或状态更新频率。
- 三种宿主在隔离且原生工具可用的测试配置中均通过自动建计划、显式计划、同会话续改、真实会话恢复和简单修改五项主路径验收；这些结果不代表所有默认配置或宿主界面已验证。
- 无工具或调用失败时仍要求说明原因并用文字清单承接；此前 Claude Code 无工具降级未通过、DSH 无工具场景受阻，实际原生写入失败分支和 UI 外观尚未验证。
- 不迁移或改写用户的 AGENTS.md、蓝图、设计、全局技能目录和历史会话。
