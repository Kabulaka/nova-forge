# Nova Forge v0.8.1

2026-09-20

## Overview

Nova Forge v0.8.1 重写项目 README，把 Nova Forge 的定位、技能边界和实际使用路径集中为一份可直接照做的中文上手指南，并加入双宿主隔离安装与临时项目端到端验收截图。

## Highlights

### 从新项目到日常开发

- 新增“30 秒理解”流程图和五个技能选择表，明确 Requirements、Architecture、Development、Review 与 Commit 的职责边界。
- 提供新项目从 Git 初始化、轻量蓝图确认、首个功能开发，到按需 Review 和本地提交的完整示例。
- 增加已有项目接入、日常请求模板、常见问题与八条提效技巧，强调真实运行验收和精确任务入口。

### 显式授权边界

- 明确普通 Development 不会自动创建设计、启动 Review、提交、push 或发布。
- 说明“继续修改”只延续当前任务，不扩大为 Review、Commit 或远程操作授权。
- 补充脏工作树保护、验证证据复用和 Commit 只消费既有有效证据的行为边界。

### 真实隔离演示

- README 内嵌 1600×1220 的终端截图，展示 Codex 与 Claude Code 开发插件在隔离目录中的安装结果。
- 仓库完整检查 54/54 通过；临时 Git 项目实际完成轻量蓝图创建和 `greet` 命令开发，示例测试 2/2 通过。
- 示例验证正常名称输出、空名称用法提示与非零退出码，并保持改动未提交、未自动启动 Review。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.8.1
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

## Requirements

- Node.js 22.5 或更高版本；插件不会自动安装 Node.js 或 Bun。
- 支持插件 marketplace 的 Codex CLI，或 Claude Code 2.1.233 及兼容版本。
- 安装后审阅并信任插件 Hook，并在安装或升级后新开宿主会话。

## Upgrade Notes

- Codex 用户把 marketplace 固定引用更新为 `v0.8.1`，重新安装或刷新插件后新开会话。
- Claude Code 用户先更新 `nova-forge` marketplace，再更新或重新安装 `nova-forge@nova-forge`，随后新开会话。
- 本版本只改进文档和演示素材，不改变技能运行时语义、插件结构或宿主要求。
- 本版本不迁移现有蓝图、设计、业务代码或需求文档，也不增加状态机、台账或持久缓存。
