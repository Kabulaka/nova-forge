# Nova Forge v0.10.0

2026-11-04

## Overview

Nova Forge v0.10.0 新增仅显式调用的独立顾问技能，让开发任务按设计与复杂度展示会话执行计划，并解除 DSH 宿主版本的精确限制。五个核心技能继续按原有职责工作，咨询不自动接入默认开发流程。

## Highlights

### 独立方案咨询

- 新增 `nova-consult`，通过全新上下文的只读子代理提供候选方案、取舍依据和验证建议；决策和实施仍由当前任务负责。
- 顾问按实际问题选择第一性原理、反例检验、消融实验设计、复杂度比较或职责分析，不执行开发、测试或实验。
- 模型与思考度默认沿用主代理的实际值并显式传入；宿主无法提供必要参数或隔离能力时报告缺口，不冒充独立咨询。
- Codex 技能元数据关闭隐式调用；Claude Code 与 DSH 遵循技能中的显式调用约定，安装包包含咨询技能及必要资源。

### 可见的会话执行计划

- 按蓝图精确链接的已确认设计实施、用户明确要求计划，或开发涉及多个依赖步骤及需分别验证的关键边界时，在编码前展示交付步骤和最低完成条件。
- 优先使用宿主提供的会话计划工具，不可用时使用简短清单；持续推进已授权开发，不增加逐项审批，不自动切换 Plan mode。
- 计划与真实进展保留在当前会话，续改时只调整受影响步骤，不自动创建设计、蓝图待办或额外状态文件。

### DSH 版本兼容修复

- 删除 `engines.dsh` 的精确版本声明，并将宿主共享技能 provider 的 peer 版本改为 `*`，避免因宿主升级而被插件管理器直接拒绝。
- 保留实际使用的官方 hooks 兼容桥与协议依赖；运行集成测试改为使用当前安装的 DSH 版本。
- 已在 DSH `0.2.1-rc.5` 的隔离 profile 中验证安装、共享资源加载、mock 模型请求、禁用、重新启用和卸载。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.10.0
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

### DeepSeek Harness

```bash
dsh plugin --profile headless add github:Kabulaka/nova-forge#v0.10.0
dsh --profile headless --dump-config
```

也可下载本 Release 的 `nova-forge-0.10.0.tgz`，校验 `SHA256SUMS` 后，通过 `dsh plugin --profile <profile> add /absolute/path/to/nova-forge-0.10.0.tgz` 安装。

## Requirements

- 共享 Hook 与维护脚本需要 Node.js 22.5 或更高版本；DSH 本身使用其宿主要求的 Node.js 运行时。
- Codex 与 Claude Code 需要支持原生插件的宿主版本；DSH 需要支持原生 bundle、技能 provider 和官方 hooks 兼容桥。
- 不限制 DSH 宿主版本不代表已验证所有版本；当前运行证据覆盖 DSH `0.2.1-rc.5`。
- 使用独立顾问需要宿主支持全新上下文的只读子代理，并能确定和传递模型及思考度参数。
- 安装或升级后审阅并信任插件 Hook，并在对应宿主或 profile 中新开会话。

## Upgrade Notes

- Codex 用户将 marketplace 固定引用更新为 `v0.10.0`，刷新或重新安装后新开会话；Claude Code 用户更新 marketplace 和插件后新开会话。
- DSH 用户在对应 profile 中更新到本版本；已有禁用选择和历史会话上下文按宿主原有方式保留。
- 咨询使用 Codex 的 `$nova-forge:nova-consult`、Claude Code 的 `/nova-forge:nova-consult` 或 DSH 的 `/nova-consult` 显式调用，普通开发请求不会自动启动顾问。
- 新版本不迁移或改写用户的 AGENTS.md、蓝图、设计与全局技能目录，也不新增持久化执行计划或开发状态。
- 结构测试和 mock 模型请求不代表真实模型已完成独立咨询、自然语言路由或执行计划的行为验收；DSH clear/compact 界面的完整操作仍需单独验收。
