# Nova Forge v0.9.1

2026-10-22

## Overview

Nova Forge v0.9.1 补齐项目运作原理图、README 图示说明，以及 DeepSeek Harness 适配设计与蓝图入口。本次为文档补充版本，运行时代码、五个共享技能及三宿主插件行为与 v0.9.0 保持一致。

## Highlights

### 运作原理可视化

- README 新增运作原理图，展示用户授权、按需切换角色、澄清交互、实现测试、独立 Review 与本地提交的协作关系。
- 明确各阶段按需触发，push、发布和其他远程写操作需要单独授权；不引入状态机、台账或强制追溯链路。
- 将原理图源文件纳入仓库，保持 README 本地图片引用可定位。

### 保存 DSH 适配设计

- 纳入 DSH 原生插件适配设计，保存安装挂载、共享技能、SessionStart、交互映射、兼容和生命周期的契约及验收场景。
- 蓝图提供精确设计入口；设计用于解释目标与契约，不作为当前运行状态或验收通过的证明。
- DSH 原生适配与真实模型开发场景沿用 v0.9.0 的已验证行为；本版本不增加运行时功能。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.9.1
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

### DeepSeek Harness

```bash
dsh plugin --profile headless add github:Kabulaka/nova-forge#v0.9.1
dsh --profile headless --dump-config
```

也可下载本 Release 的 `nova-forge-0.9.1.tgz`，校验 `SHA256SUMS` 后，通过 `dsh plugin --profile <profile> add /absolute/path/to/nova-forge-0.9.1.tgz` 安装。

## Requirements

- 共享 hook 与维护脚本需要 Node.js 22.5 或更高版本；插件不会自动安装 Node.js 或 Bun。
- Codex 与 Claude Code 需要支持原生插件的宿主版本。
- DSH 支持目标仍为 `0.2.1-rc.2`，需使用该宿主支持的 Node.js 运行时。
- 安装或升级后审阅并信任插件 hook，并在对应宿主或 profile 中新开会话。

## Upgrade Notes

- Codex 用户将 marketplace 固定引用更新为 `v0.9.1`，刷新或重新安装后新开会话。
- Claude Code 用户更新 marketplace 和 `nova-forge@nova-forge`，随后新开会话。
- DSH 用户在对应 profile 中更新版本；已有禁用选择与历史会话上下文保持原有处理方式。
- 本版本不迁移或改写用户的 AGENTS.md、蓝图、设计和全局技能目录。仓库中的图示与设计资料供阅读，不会作为插件运行时状态维护。
- DSH 交互式澄清、独立 Review 使用链及 clear/compact 界面完整操作仍未验收，本次文档补充不改变该证据边界。
