# Nova Forge v0.7.2

2026-09-20

## Overview

Nova Forge v0.7.2 收敛 `nova-development` 的重复验证开销。Development 现在把“相关内容和环境未变化时，不得重复执行已经通过的命令”作为验证批次的首要约束，同时继续保留风险相称的代码搜索、测试、静态检查、任务差异核对和真实验收。

## Highlights

### 复用仍然有效的验证证据

- 相关代码、配置、测试、工具环境和验收要求均未变化时，不再重复执行已经通过的命令。
- 内容变化、结果失败或不完整、覆盖不足、影响无法限定，或者用户明确要求重跑时，仍执行受影响验证或完整验收。
- 去重约束前置到验证批次首句，并由插件结构测试固定，未引入状态机、台账、持久缓存或命令编排器。

### 受控 Plain/Nova 验收

- 使用相同完整任务、初始代码、`gpt-5.6-sol`、`high` reasoning 和 provider 运行 5×5 交错配对，Plain/Nova 共 10/10 个样本通过行为、测试、输入不变、usage 和未提交验收。
- 本轮两轮总计的 Nova 成对中位数增量为：耗时 +5.5%、原始 token +14.8%、有效 token +22.6%、命令数 +8.3%；20 个首轮/续改阶段均未出现内容不变时重复执行成功命令。
- 性能数据只说明本次受控任务和运行时段；它不证明全部改善都由单句调整造成，也不外推为所有项目的固定 Nova 开销。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.7.2
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

## Requirements

- Node.js 22.5 或更高版本；插件不会自动安装 Node.js 或 Bun。
- 支持插件 marketplace 的 Codex CLI，或 Claude Code 2.1.233 及兼容版本。
- 安装后审阅并信任插件 Hook，并在升级后新开宿主会话。

## Upgrade Notes

- Codex 用户把 marketplace 固定引用更新为 `v0.7.2`，重新安装或刷新插件后新开会话。
- Claude Code 用户先更新 `nova-forge` marketplace，再更新或重新安装 `nova-forge@nova-forge`，随后新开会话。
- 本版本不迁移现有蓝图、设计、业务代码或需求文档，也不增加状态机、台账或持久缓存。
- 必要的代码搜索、构建、测试和真实验收仍然保留；只有仍有效的成功验证可以复用。
