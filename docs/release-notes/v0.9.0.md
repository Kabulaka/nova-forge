# Nova Forge v0.9.0

2026-10-22

## Overview

Nova Forge v0.9.0 新增 DeepSeek Harness 原生插件支持。五个共享技能与 SessionStart 全局规则可通过 DSH 的 profile bundle 安装、禁用和卸载；Codex 与 Claude Code 继续使用现有插件入口。本版本同时修复存在真实互斥选项时未优先调用可用结构化提问工具的问题。

## Highlights

### DeepSeek Harness 原生挂载

- 适配 DSH `0.2.1-rc.2`，通过官方技能 provider 与 Claude Code hooks 兼容桥挂载包内资源。
- 安装到指定 profile，五个技能和相对引用从包内加载；不复制全局技能，也不修改用户或项目 AGENTS.md。
- SessionStart 在 `startup`、`resume`、`clear`、`compact` 来源注入共享规则及包内资源根目录；共享 hook 执行时规则缺失仍保持 fail-open。
- 重复安装不会重复注册；更新保留用户禁用选择，原生卸载及插件作用域释放会清理技能和 hook，并取消运行中的 hook 子进程。
- 损坏的包资源、无效命令或 matcher、未覆盖约定来源的配置在插件注册前失败。

### 保持原宿主行为并修复澄清交互

- Codex、Claude Code 的插件入口和共享规则保持现有行为；加载技能和执行共享 hook 不要求安装 DSH SDK。
- 2–3 个真实互斥选项遇到本轮可用的结构化提问工具时必须先调用；可选选择和阻塞选择使用同一规则。
- 仅在工具未暴露、明确不可用或非交互通道中降级为普通文本，不为此切换 Plan mode 或改变宿主配置。

### 验证覆盖

- 仓库完整检查 59/59 通过；默认 npm 干净安装、包结构与资源完整性检查通过。
- DSH 隔离原生集成覆盖安装、五技能加载、首请求规则、四种 SessionStart 来源、禁用/恢复、卸载和运行中 hook 清理；模型传输使用 mock。
- 本机 DSH 真实模型会话通过原生 `skill` 工具加载 `nova-development`，完成小函数开发并运行测试；独立复跑 2/2 通过。会话记录确认技能全文和全局规则完整加载。
- Codex、Claude Code 的隔离安装/卸载、五技能缓存及共享 hook 输出回归通过。

## Installation

### Codex CLI

```bash
codex plugin marketplace add Kabulaka/nova-forge --ref v0.9.0
codex plugin add nova-forge@nova-forge
```

### Claude Code

```text
/plugin marketplace add Kabulaka/nova-forge
/plugin install nova-forge@nova-forge
```

### DeepSeek Harness

```bash
dsh plugin --profile headless add github:Kabulaka/nova-forge#v0.9.0
dsh --profile headless --dump-config
```

也可下载本 Release 的 `nova-forge-0.9.0.tgz`，校验 `SHA256SUMS` 后通过 `dsh plugin --profile <profile> add /absolute/path/to/nova-forge-0.9.0.tgz` 安装。

## Requirements

- 共享 hook 与维护脚本需要 Node.js 22.5 或更高版本；插件不会自动安装 Node.js 或 Bun。
- Codex 与 Claude Code 用户需要支持原生插件的宿主版本。
- DSH 支持目标固定为 `0.2.1-rc.2`，需使用该宿主支持的 Node.js 运行时；本机原生验收使用 Node.js 22.23.3。
- 安装或升级后审阅并信任插件 hook，并在对应宿主或 profile 中新开会话。

## Upgrade Notes

- Codex 用户将 marketplace 固定引用更新为 `v0.9.0`，刷新或重新安装插件后新开会话。
- Claude Code 用户更新 `nova-forge` marketplace 和 `nova-forge@nova-forge`，随后新开会话。
- DSH 用户按 profile 安装；其他 profile 不会自动启用。禁用覆盖会保留，已有会话历史上下文不会因禁用或卸载而清除。
- DSH 交互式澄清、独立 Review 使用链及 clear/compact 界面完整操作尚未验收；集成测试中的来源事件转发不等同于界面操作。
- 本版本不迁移蓝图或设计文件，不增加独立服务、状态机、台账、自动 Review、提交或发布行为。
